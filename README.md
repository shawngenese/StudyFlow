# StudyFlow — Student Personal OS

Local-first SPA (React 19 + Vite) — beyond a todo list.

**Views:** Dashboard · List · Board · Calendar · Habits · Focus · Notes

**Features:** Tasks with estimates & recurring (daily/weekly), natural-date parsing (chrono-node), markdown notes + images (DOMPurify), habits with streaks, pomodoro focus timer with sessions, docs per course, goals, command palette (Ctrl+K), board drag-drop, undo/redo, import/export, warm paper rebrand (#c45a2a terracotta).

**Run:** `npm install && npm run dev` · `npm run build` · `npm run test`
**Storage:** `localStorage shawn-todos-v3` (migrates from v2) — stays local.
**Shortcuts:** `n` new task, `/` search, `Ctrl+K` palette, `Ctrl+Z` undo.
